**ABC특허법률사무소(ABC IP LAW)** 는 AI·소프트웨어·반도체 장비 등 딥테크 분야에서 출원과 특허 포트폴리오 구축을 함께해 온 한국 변리사 사무소입니다.

개발팀이 이미 AI 에이전트(Claude Code, Codex, Gemini CLI)와 일하고 있다면, 변리사가 특허를 찾고 거르는 방식도 그 에이전트에게 맡길 수 있습니다. 이 계정에서는 그런 스킬을 누구나 쓸 수 있게 공개합니다.

## 특허 포트폴리오 발굴 스킬

스타트업·중소기업 개발팀이 자기 프로젝트에서 실행하면, 에이전트가

1. 사업과 고객에서 출발해 제품을 기술 요소로 나누고, 코드에서 특허 후보를 찾습니다.
2. 성립성·신규성 위험·진보성·권리 실효성·영업비밀 여부로 **특허성을 예비 판정**합니다.
3. 원천·핵심 → 응용 → 신사업·해외로 이어지는 **포트폴리오를 설계**하고 빈 곳을 짚습니다.
4. 출원할 만한 발명마다 발명신고서를 대신할 **기술 설명서**를 씁니다.

```text
/plugin marketplace add abciplaw/startup-ip-skills
/plugin install abciplaw@startup-ip-skills
/abciplaw:patent-portfolio
```

결과물은 프로젝트 안 `patent-portfolio/` 폴더에만 저장되고, 사용자가 직접 보내기 전에는 어디로도 전달되지 않습니다. Codex·Gemini CLI·기타 에이전트에서 쓰는 방법은 [설치 안내](https://github.com/abciplaw/startup-ip-skills/blob/main/abciplaw/README.md)에 있습니다.
